# 地獄のICT — 宣伝トレイラー構成案

**用途:** 宣伝用トレイラー  
**想定尺:** 約40〜45秒  
**想定素材:** 文字なしのキーフレーム画像＋動画生成サービスによる短尺映像化＋編集時のテロップ／音響

---

## 1. コンセプト

参加者自身が、業務崩壊した「聖クロノス総合病院」へ放り込まれる疑似体験として構成する。

ゲームの教育テーマや罠の内容は説明せず、以下の魅力に集中する。

- 同時多発するアウトブレイク
- 絶望的な業務量
- AIを使わなければ処理できない切迫感
- チーム同士のレース
- 院長・看護部長・事務長による理不尽な無茶振り

宣伝上のメインコピーは次のとおり。

> **同時多発するアウトブレイク。**  
> **絶望的な業務量。**  
> **次々に襲いかかる、最悪最恐のシチュエーション。**  
> **AIを駆使して制圧し、最速で生還せよ。**

---

## 2. トレイラー構成

| 時間 | 画面 | 音声・コピー |
|---:|---|---|
| 0〜2秒 | 黒画面。赤い警報灯だけが回り始める | PHS、院内アラーム、電話、プリンター音が一斉に鳴る |
| 2〜5秒 | 黒い巨大建築としてそびえる聖クロノス総合病院。複数の病棟だけが赤く点灯 | 院内放送「感染制御チーム、至急応答してください」 |
| 5〜8秒 | **案A:** 病院の各階で赤い警告が同時発生する／**案B:** ICT室へPHS・電話・FAX・メールで複数のアウトブレイク報告が立て続けに入る | **「同時多発するアウトブレイク。」** |
| 8〜11秒 | 暗い廊下。複数のPHS、検体搬送箱、感染対策カート、警告灯が同時に動く | 重い心拍音が始まる |
| 11〜14秒 | 古いPC、増殖する緊急メール、床まで吐き出された帳票、壊れたExcel | **「絶望的な業務量。」** |
| 14〜17秒 | 一人称視点。机へICTの職員証が投げられ、奥に三幹部の影が立つ | 院長「ようこそ、聖クロノス病院へ。優秀なICTの諸君」 |
| 17〜20秒 | 事務長が捺印済みの大量の書類を差し出す | 事務長「署名だけで結構です」 |
| 20〜23秒 | 看護部長が黒いスクラブ姿で、赤ペンをこちらへ向ける | 看護部長「今すぐ始めてください」 |
| 23〜26秒 | 院長が眼鏡を押し上げ、不敵に笑う。背後には処理不能な量の依頼と記者会見場 | 院長「皆さんなら、このくらいは簡単でしょう？」 |
| 26〜30秒 | Excel、職員通知、翻訳、ポスター、会見資料が高速で積み上がる | **「次々に襲いかかる、最悪最恐のシチュエーション。」** |
| 30〜34秒 | AIへ大量のデータと指示を投入。汚い表が整い、文書と画像が次々に完成する | 音楽が一気に加速 |
| 34〜38秒 | リーダーボード上で複数チームが競争。ステージ扉が次々に解錠される | **「AIを駆使して制圧し——」** |
| 38〜42秒 | 記者会見室の扉が開く。無人の演台へ無数のフラッシュが浴びせられる | **「最速で生還せよ。」** |
| 42〜46秒 | 院長、看護部長、事務長が並んでこちらを見下ろす。暗転してタイトル | **「地獄のICT」**／**「最速で、生還せよ。」** |

## 3. ネタバレ防止方針

教育上のサプライズを守るため、宣伝トレイラーでは以下を出さない。

- AIの嘘や存在しない出典
- 個人情報送信の警報
- NotebookLMによる復旧
- 罠の原因や回避方法
- 患者とバッドエンド
- 「AIを疑え」という直接的な説明

ゲーム本編のテーマコピー「速く、かつ疑え。」は宣伝では使用せず、トレイラーでは **「最速で、生還せよ。」** を使用する。

AIは有能な武器としてのみ描き、何らかの罠があることも明示しない。

---

## 4. 必要なキーフレーム画像

1. 聖クロノス総合病院の外観
2A. 複数病棟で警告が発生する病院断面
2B. ICT室へ複数のアウトブレイク報告が立て続けに着弾する場面
3. 警報が鳴る暗い病院廊下
4. 絶望的な業務量のICTデスク
5. 職員証を投げられる一人称視点
6. 書類を差し出す事務長の院内シーン
7. 赤ペンで命令する看護部長の院内シーン
8. 記者会見を背にした院長
9. AIによって業務が高速処理される作戦室
10. 複数チームが競争するリーダーボード演出
11. 無人の記者会見場
12. 三幹部が並ぶ最終キービジュアル

三幹部の場面は、`assets/images/test/characters/` 以下の設定画像を人物参照として使用する。

---

## 5. ビジュアルルール

- 基本色は黒、チャコール、冷たい白、深紅
- 病院は写実的な施設ではなく、黒と赤に支配された劇画調の業務地獄として描く
- 太い輪郭、細かなクロスハッチ、強い赤のリムライトを使用する
- 参加者の顔は映さず、一人称視点を中心にする
- 患者は宣伝トレイラーには登場させない
- 三幹部は完全な人間として描き、人外要素を入れない
- 生成画像には文字を描き込まない
- コピー、台詞、タイマー、リーダーボード、タイトルは動画編集時に重ねる

---

## 6. 音響方針

- 冒頭は音楽を使わず、PHS、アラーム、電話、プリンターなどの業務音を重ねる
- 「絶望的な業務量。」から低い心拍音を加える
- AIによる処理開始と同時にテンポを上げる
- 記者会見場のフラッシュ音をクライマックスにする
- タイトル表示直前で一度無音にし、最後に低い衝撃音を入れる

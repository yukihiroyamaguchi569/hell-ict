## 0. プロジェクト設定

```text
タイムライン解像度: 1280 × 720
フレームレート:     24 fps
オーディオ:         48 kHz
総尺:               46 秒
```

### 時刻の表記について

**24 fps では 1フレーム = 1/24 秒 ≒ 0.0417 秒。** 本書の秒数はすべて**フレーム境界に乗る値**に
揃えてある。任意の小数秒を書くと Resolve 側の丸めで映像・台詞・効果音・テロップの同期が
文書とずれるため。

フレーム境界を外れる値が必要になった場合は、**フレーム数を正とし、秒数は参考値**として扱う。
本書では境界が自明でない箇所にタイムコード `HH:MM:SS:FF` とフレーム数を併記している。

**本書の時刻はすべて本編先頭を `0` とする相対値。** Resolve のタイムラインは既定で
`01:00:00:00` から始まる（§1.0 参照）ため、タイムライン上の絶対タイムコードは
**本書の値に1時間を足したもの**になる。

| 本書の表記 | Resolve のタイムライン上 |
|---|---|
| `00:00:00:00`（0.0秒） | `01:00:00:00` |
| `00:00:26:00`（26.0秒） | `01:00:26:00` |
| `00:00:46:00`（46.0秒） | `01:00:46:00` |

秒とフレームの桁は変わらないので、頭の `01` を足すだけで読み替えられる。
なお §1.0 の手順（追加・F9）で組む限り絶対タイムコードを入力する場面はないため、
通常この読み替えは不要。

**フレームレートはプロジェクト作成直後に設定する。** クリップ読み込み後は変更に制約が出る。

読み込んだら、**Veo 生成分11本のオーディオを全て無効化する。** ネイティブ音声が焼き込まれており、
鳴っていると自前の音響と混ざる。カット01（Kling）のみ音声トラックを持たない。

### 1.0 並べ方（Resolve）

**追加（Append・F9）だけで組む。** 上表のカットは §2 のモンタージュも含めて隙間なく連続するため、
Source Viewer で `I` / `O` を打って **F9** を押す作業を順に繰り返せば、位置合わせは一切不要。

```text
01 → 02b → 03 → 04 → 05 → 06 → 07 → 08
   → モンタージュ 1〜8（§2）→ 09 → 10 → 11 → 12
```

モンタージュを後回しにして区間を空けると、埋めるときに以降が全部ずれる。**順番どおり挟む。**

モンタージュには静止画6枚を使うため、`assets/images/test/characters/` の該当ファイルも
あらかじめ Media Pool へ読み込んでおく（§2 の表を参照）。

この方法なら**タイムラインの開始タイムコードは無関係**。Resolve は放送慣習により既定で
`01:00:00:00` から始まる（本編前にバー・スレート・カウントダウンを置く余地を確保するため）が、
再生ヘッドを絶対位置へ飛ばす操作をしないので、既定のままでよい。

### 1.1 冒頭2秒の黒画面

構成案は「黒画面。赤い警報灯だけが回り始める」と指定している。新規素材は作らない。

1. カット01 を 0.0〜5.0 まで通しで置く
2. その上（V2）に**黒の単色（Solid Color）**を重ね、不透明度 95% 程度にする
3. 建物の赤い窓明かりだけが暗闇から滲む状態になる
4. 1.5〜2.0 秒あたりで黒の不透明度を 0% へフェードし、カット01 を現す

カットで切り替えるより、**闇から病院が浮かび上がる**方が構成案の「落差」に合う。
不透明度は素材を見ながら調整する（95% は出発点）。

## 2. モンタージュ（26.0〜30.0）

対応するカットが存在しない唯一の区間。コピーが「**次々に**襲いかかる」であり、
1枚の画で受けるビートではないため、複数の素材を刻んで繋ぐ。**新規生成は不要。**

### 素材選定の原則

**このビートでは、見たことのある画を出さない。** 仕事は「新しいものが来続ける」ことを示すこと。
使い回しはその意味を自分で否定する。**見慣れた画は初見の画より速く認識されるため、
0.5秒の刻みでも「さっきの」と分かる。**

そこで主体を**キャラクター設定画の静止画**に置く。`assets/images/test/characters/` の
三幹部のバストは**本編映像に出てこない画角**であり、すべて初出になる。

**静止画は動画より強く切れる。** モーションブラーもドリフトも無いので、速いカットでは一撃になる。
動 → 静 → 動 のリズムは、全部を動画で組んだモンタージュには作れない。

### 配置

**尺はフレーム数を正とする。** 秒数は参考値（24 fps では 0.9 秒などがフレーム境界に乗らない）。

| # | タイムライン（TC） | 素材 | イン点 | 尺 |
|---|---|---|---|---|
| 1 | `00:00:26:00`〜`00:00:26:20` | 動画 `02b-ict-incoming-outbreak-reports` | 3.50 | **20f** |
| 2 | `00:00:26:20`〜`00:00:27:10` | 静止画 `administrative-director-three-quarter-bust-v1` | — | **14f** |
| 3 | `00:00:27:10`〜`00:00:27:22` | 静止画 `director-front-bust-v1` | — | **12f** |
| 4 | `00:00:27:22`〜`00:00:28:08` | 静止画 `nursing-director-three-quarter-bust-v1` | — | **10f** |
| 5 | `00:00:28:08`〜`00:00:28:17` | 静止画 `administrative-director-front-bust-v1` | — | **9f** |
| 6 | `00:00:28:17`〜`00:00:29:01` | 静止画 `director-three-quarter-bust-v1` | — | **8f** |
| 7 | `00:00:29:01`〜`00:00:29:08` | 静止画 `nursing-director-front-bust-v1` | — | **7f** |
| 8 | `00:00:29:08`〜`00:00:30:00` | 動画 `04-overwhelming-ict-workload` | 5.50 | **16f** |

合計 20+14+12+10+9+8+7+16 = **96フレーム = 4.000秒**。

静止画は 14 → 12 → 10 → 9 → 8 → 7 と加速し、**顔が次々に浴びせられる**形になる。

**前後を動画で挟むのは意図的。** 4秒すべてを静止画にすると「映像が壊れた」と読まれる危険があるため、
動きで入って動きで抜ける。末尾を `04`（業務量）にすることで、34秒の
「AIを駆使して制圧し——」が**何を制圧するのか**も保たれる。

動画2本のイン点は、**それぞれ §1 で使う窓**（`02b` は 0.00〜3.00、`04` は 2.50〜5.50）と
重ならない位置を選んである。

### 静止画の扱い

- **顔に寄せてトリミングする。** 素材は縦長。7〜14フレームでは全身を読む時間がない
- **ズームもパンも付けない。** 動画の中で1枚だけ止まっていることが効果であり、動かすと消える
- Resolve では静止画は既定5秒で配置されるので、クリップと同様に端を詰める

### 調整の余地

**この区間は繋いでから最も調整が要る。** 刻みが速すぎて何も見えない、逆に間延びする、
どちらも起こりうる。まず上表どおり置き、再生して感覚で詰める。

**ただし合計96フレームは動かさないこと。** 内訳（20/14/12/10/9/8/7/16）はリズムの設計であって
拘束条件ではないが、**総量は下流の同期を握っている**。1カットを縮めたら別のカットを同じだけ
伸ばし、**96フレーム内で再配分する**。

総量が変わると 26.0〜30.0 秒の区間が伸縮し、カット09〜12 がすべてずれる。
34.0秒（リーダーボード）・38.0秒（フラッシュ音）・42.0秒（タイトルの衝撃音）に置く
効果音も同じだけ外れる。**守るべき数字はこの1つだけ**なので、内訳は自由に触ってよい。

**モンタージュの打撃音は1トラックに収まらない。** `impact-title` は実尺 **2.14秒**あるのに対し、
8発の間隔は **0.29〜0.83秒**しかない。1トラックには同時に1クリップしか置けないため、
物理的に並べられない。

**A8 と A9 へ交互に置く。**

```text
A8: 1発目 → 3発目 → 5発目 → 7発目
A9: 2発目 → 4発目 → 6発目 → 8発目
```

各音が間隔の2倍まで鳴り続けられる。これは音としても良い方向で、**前の音の余韻に次の音が重なり**、
カットが加速するにつれて団子になっていく——加速が音圧としても伝わる。
それでも 2.14秒には届かないので、各クリップ末尾に短いフェードアウトを付けて切る。

音量は大きく下げる。うるさければ発数を減らしてよい。**加速が伝わることが目的**であり、
全カットに当てることではない。42秒のタイトルの一発だけは別扱いで、フル音量で最後まで鳴らす。

**同じファイルを別音量で使うのにトラックを分ける必要はない。** Resolve はクリップ単位で音量を持てる
（クリップ選択 → Inspector → Volume、またはクリップ上の水平線をドラッグ）。1発目を調整してから
コピーすれば、音量ごと複製される。

### 3.2 素材の尺と繰り返し

**効果音の実尺は、鳴らしたい区間より短いものが多い。** 4本は繰り返して並べる必要がある。

| ファイル | 実尺 | 必要 | 対処 |
|---|---|---|---|
| `alarm-emergency` | 3.99秒 | 11.0秒 | **3回** |
| `phs-ring` | 4.63秒 | 6.0秒 | **2回** |
| `printer-dot-matrix` | 5.20秒 | 10.0秒 | **2回** |
| `heartbeat-low` | 7.42秒 | 19.0秒 | **3回** |
| `phone-desk-ring-a` | 11.42秒 | 10.5秒 | そのまま |
| `phone-desk-ring-b` | 5.54秒 | 5.0秒 | そのまま |
| `countdown-electronic` | 5.97秒 | 4.0秒 | そのまま |
| `camera-shutter-burst` | 4.27秒 | 4.0秒 | そのまま |

**繰り返しの周期は揃えないこと。** 実尺がばらばら（3.99 / 4.63 / 5.20秒）なのは好都合で、
重ねると位相が合わないまま延々ずれ続けるため、11秒間まったく同じパターンが再現しない。
これが「混沌とした病院の音」になる。**揃えると機械的な反復として耳につく。**

**`heartbeat-low` だけは例外。** 継ぎ目が拍として成立していないと破綻する。他の音は多少ずれても
環境音として溶けるが、心拍は途切れた瞬間に嘘になる。波形で拍の切れ目を見て、そこで切ってから
繰り返す。ただし 14〜23秒には台詞が乗るため、多少の継ぎ目は台詞に隠れる。完璧を目指さなくてよい。

繰り返しの境目で「プチッ」と鳴る場合は、クリップの角の**フェードハンドル**を数フレーム引いて
短いフェードを付ければ消える。

### 3.3 院内放送の処理（A2）

館内スピーカー越しの質感を作る。**Fairlight ページ**で、A2 トラックに対して行う。

**EQ**（ミキサーのチャンネルストリップの EQ セクション）

```text
ハイパスフィルター（低域カット）: 400 Hz
ローパスフィルター（高域カット）: 3.5 kHz
1〜2 kHz を +3 dB 程度
```

300〜4000 Hz だけを残すのが、電話・館内放送の帯域。上下を削るほど機械越しの音になる。

**歪み**: Effects Library → FairlightFX → **Distortion** を A2 へドラッグ。

**かけすぎないこと。** 「感染制御チーム、至急応答してください」は物語上の呼び出しであり、
何を言っているか聞き取れなくなったら本末転倒。ざらつきが加わる程度で止める。

トラックの **S（ソロ）** で単体を調整したあと、必ずソロを外して**業務音4系統と重なった状態**で
聴き直す。単体では良くても混ざると埋もれる。

### 3.4 冒頭11秒の作り方

構成案は「重ねる」と指定している。**順番に鳴らすのではなく、同時に鳴らして飽和させる。**
A3〜A6 の4系統が常時重なる状態を作り、開始をわずかにずらして機械的な同期を避ける。

全体の音量は、11秒で心拍が入る瞬間に**一段下げる**。業務音が引いて心拍が立ち上がることで、
「絶望的な業務量。」のコピーが刺さる。

### 3.5 音楽

**必要。** 当初「まず入れずに組み、間が持たなければ足す」としていたが、これは構成案の誤読だった。
§6 の「AIによる処理開始と同時にテンポを上げる」は、**音楽の存在を前提にした指定**である。
音楽がなければテンポを上げる対象が存在しない。「冒頭は音楽を使わず」は、
後から入ってくることを前提にした書き方だった。

実際、映像・台詞・効果音まで組んだ段階で通して見たところ「ワクワクしない」という評価になり、
テロップと音楽を足して解消した。

- **30.0〜46.0秒の16秒分だけでよい。** 冒頭の音楽なしの設計は変えない
- **最初から build する曲を選ぶ。** 平坦な曲から加速を作るのは難しい
- **曲の頂点を42.0秒（タイトル）に合わせる。** 曲頭からではなく、頂点から逆算して置く位置を決める
- 系統は暗い・緊迫感のあるもの（`cinematic trailer` `dark tension` `epic build`）
- **41.5〜42.0秒では音楽も切る。** 効果音だけ切っても音楽が鳴っていれば無音にならない

調達は DOVA-SYNDROME（無料・商用可）。ただし**楽曲ごとに作曲者が独自条件を設定できる**ため、
使用曲の個別ページの利用規約を必ず確認すること（クレジット表記必須のものがある）。

### 3.6 音量

**Bus（Main）が振り切れやすい。** 個々のトラックが適正でも、10本足せば合計は超える。
密度が上がるのは **0〜11秒**（業務音4系統＋院内放送）と **38〜42秒**（フラッシュ音＋音楽の頂点）。

- **ピークは -3 dB 前後**に収める。Bus のフェーダーで下げる（Resolve は内部 32bit float 処理のため、
  Bus で下げても歪みは残らない）
- 突発的なピークが残るなら、Bus に **Limiter**（FairlightFX）を挿し、**Ceiling を -1 dB**
- **メーターの赤い帯は「歪んでいる」意味ではない。** 警告は 0 dB への到達と、
  メーター最上部のクリップインジケーターの点灯（一度点くと手動リセットまで消えない）

**下げた後は台詞が聞こえるか必ず確認する。** 埋もれたら Bus を戻すのではなく、
台詞トラックだけを上げる。優先順位は次のとおり。

```text
台詞 ＞ 衝撃音・フラッシュ音 ＞ 音楽 ＞ 業務音
```

**台詞が聞き取れることが最優先。** 院長の「ようこそ、聖クロノス病院へ」が埋もれたら
そのカットは意味を失う。

## 4. テロップ（V2以上）

構成案 §5 の方針により、映像素材に文字は焼き込まれていない。すべてここで重ねる。

**テロップは装飾ではなく、この作品の唯一のメッセージ伝達手段である。** これが無いと、
レースであることも AI を使う研修であることもゲームであることも画面上に存在せず、
「暗い病院の映像」にしかならない。**映像と音より先に入れてよい。**

| 出す時刻 | 内容 | 種別 |
|---|---|---|
| 5.0 | 同時多発するアウトブレイク。 | コピー |
| 11.0 | 絶望的な業務量。 | コピー |
| 26.0 | 次々に襲いかかる、最悪最恐のシチュエーション。 | コピー |
| 34.0 | AIを駆使して制圧し—— | コピー |
| 34.0 | （チーム名・タイムのリーダーボード表示） | UI・優先度低 |
| 38.0 | 最速で生還せよ。 | コピー |
| **42.0** | **地獄のICT** ／ 最速で、生還せよ。 | タイトル |

### 出し方

**カットの尺いっぱい出しっぱなしにしない。** 3〜4秒あるカットに3〜4秒出すと画面が止まって見える。
**出したら1.5〜2秒で消す。** 残りは映像だけにする。文字が消えた後の間が次のカットへの助走になる。

**フェードインさせず、ハードカットで出す。** 音の当たりと同時にパッと出す。
配置は音の出来事と一致するよう設計してある。

| テロップ | 同時に起きる音 |
|---|---|
| 11.0「絶望的な業務量。」 | 心拍が始まる |
| 38.0「最速で生還せよ。」 | フラッシュ音のクライマックス |
| 42.0 タイトル | 無音の後の衝撃音 |

**タイトルは42.0秒、衝撃音と同時に出す。** 0.5秒空けると音と文字の因果が切れる。
**無音 → ドン ＋ タイトル**が最も強い形。

### 位置と体裁

**下寄りで統一する。** この素材は中央が埋まっている（三幹部の顔、モンタージュの顔のアップ）。
中央に置くと顔にかぶる。一方どのカットも下部は暗い（机・床・椅子・影）ので白い文字がよく抜ける。
カット12は生成時に「画面の左右と下の暗い部分は暗いまま変化しない」と指定してあり、
**タイトルを置くために意図的に空けた領域**である。

- 画面の**下から20〜25%**にベースライン。6箇所すべて同じ高さに揃える
- 左右は中央揃え
- 画面の端から**10%以内には入れない**（720p なら左右各128px・上下各72px）
- 「次々に襲いかかる、最悪最恐のシチュエーション。」は長いので2行に折り返してよい。
  その場合も**最終行のベースラインを他と揃える**

書体は黒地に映える太いゴシック。基本色は白と深紅（構成案 §5 のビジュアルルール）。
**「速く、かつ疑え。」は使わない**（本編テーマのコピーであり、宣伝では伏せる）。

1つ作り込んだらコピーして文言だけ差し替える。ゼロから作ると必ずばらつく。

台詞は音声で入るため字幕は付けない。付ける場合は別途判断する。

### Resolve での作り方

Effects Library → `Titles` → **Text+** を映像より**上のトラック**（V2以上）へドラッグ。

**Text+ は配置しただけでは何も表示されない。** 中身が空の状態で置かれるため、
クリップを選択して Inspector の **Text → Styled Text** に入力して初めて出る。
表示されない場合は、再生ヘッドがクリップ上にあるか・トラックが映像より上か・
トラックが有効かも確認する。

## 5. 書き出し

```text
解像度: 1280 × 720
形式:   H.264 / MP4
音声:   AAC 48kHz ステレオ
```

720p のまま出す。素材が 720p であり、拡大しても実体が増えないため。

Deliver ページで **Filename** と **Location** を設定してから `Add to Render Queue`。
**キューに入れただけでは始まらない。** Render Queue パネル下部の **Start Render** を押す。

書き出したファイルはリポジトリに置かない。

## 6. 確定した判断

繋いで再生して初めて決まる、としていた項目の結論。

| 項目 | 結論 |
|---|---|
| **音楽の要否** | **必要**。無しでは成立しなかった（§3.5） |
| **テロップの重要度** | **最重要**。無いとメッセージが存在しない。映像・音より先に入れてよい（§4） |
| **看護部長のテイク** | **Kore で確定**。全体のミックスに乗せても違和感なし |
| **院長のテイク** | **Schedar**。当初 Umbriel を採用したが、画と音楽に乗せると**声が軽かった** |
| **事務長のテイク** | **Achird**。当初の Iapetus も同じ理由で軽かったため録り直した |
| モンタージュの刻み | 設計どおり（20/14/12/10/9/8/7/16 フレーム）で通した |

### 声の選定で分かったこと

**単体で聴き比べた判断は、画と全体のミックスに乗せると変わる。** 院長は無音の状態では
Umbriel が良く聞こえたが、完成形では軽かった。

**男性キャラクターには男性寄りに分類されるボイスを選ぶ。** Gemini TTS のボイス一覧では
Schedar・Gacrux が男性寄り、Umbriel・Iapetus・Kore・Autonoe・Zubenelgenubi が女性寄りとされる。
特性（Even / Gravelly など）だけで選ぶと、低域の不足に後から気づくことになる。

院長・事務長ともこの理由で差し替えている。**男性2役を続けて外した**ので、
今後キャラクターの声を選ぶときは、特性より先に男女の分類を見ること。

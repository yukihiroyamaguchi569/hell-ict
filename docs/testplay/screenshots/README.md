# デブリーフィング用スクリーンショット

[デブリーフィング_スライド.html](../デブリーフィング_スライド.html) が読む画像を置く。**まだ撮っていない画像は、スライドの枠にファイル名が出る**ので、下記の名前で保存すればそのまま差し替わる。

撮影は本番と同じ配信URL（`https://hell-ict.yukihiroyamaguchi.workers.dev`）の画面から行う。当日朝の通しプレイのついでに撮ると、閾値較正後の実画面と揃う。

| ファイル名 | 撮るもの |
|---|---|
| `fever-03.png` | Prologue のヘッダー（`発熱 3`）。ヘッダー帯だけを横長に切る |
| `fever-05.png` | Stage 2 解錠直後のヘッダー（`発熱 5`） |
| `fever-14.png` | Stage 4 開始時のヘッダー（`発熱 14`）。赤帯が出ていてもよい |
| `prologue-mail3.png` | Prologue のメール3（夜勤師長の申し送り）。末尾の発熱の一文が入るように |
| `stage2-linelist.png` | Stage 2 の整形後ラインリスト。患者ID `005` / `6` / `008` の行が入るように |
| `stage3-manual.png` | Stage 3 のマニュアルビューア。第5章の解除基準（治療完了後24時間）が読める位置 |

3枚並べるスライド（`fever-*.png`）は、**3枚とも同じ幅・同じ切り方**にする。並べたときに数字だけが変わって見えることが、このスライドの効き目そのものになる。

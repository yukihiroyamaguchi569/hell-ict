地獄のICT

AIを相棒に、崩れかけた病院を立て直せ
ブリーフィング

01これは、AI研修です

ゲームの形をしていますが、狙いはひとつです。

  • AIに仕事を渡せる——何が欲しいかを、言葉にして渡す
  • AIの出した物を扱える——使うか、直すか、捨てるかを自分で決める
  • AIを前提に段取りが組める——手でやるか、任せるかの判断
  • 講義はしません。聞いて覚えるのではなく、やって身につけてもらいます。
これは、AI研修です

02先に謝っておきます。これは難しいです

「地獄のICT」という名前は、誇張ではありません。

  • 難易度は下げていません。地獄のように大変です
  • 時間内に全部終わらないのが普通です。詰まる、間に合わない、失敗する
  • それも含めて、このゲームの体験です
  • できていないのは、あなたたちだけではありません。どのチームも止まっています
  • だから、手を止めて悩むより、詰まったまま試し続けるほうが前に進みます。
これは難しいです

03舞台：聖クロノス総合病院

400床・地方中核病院。電子カルテは2003年製です。

  • 皆さんは、前任のICNが急に辞めた穴を埋めるために外部から派遣された感染制御チーム
  • 今日が着任初日です。引き継ぎは、あまりありません
  • 院内では、複数の火の手が同時に上がりかけています
舞台：聖クロノス総合病院

04チームとPC

  • 個人のPC・スマホは使いません。
  • マウスはありません。トラックパッドで操作します。
    • 二本指でクリックすると右クリックと同じようにメニューが表示されます
    • 席は固定せず、ステージごとに交代してください（全員でAIをさわりましょう）
  • チーム名は、この後の入室画面でチームごとに決めてもらいます
チームとPC

05進み方

ステージ制のレースです。課題を提出して通れば、次が開きます。

  • 全チーム同時スタート。最初にゴールしたチームが優勝です
  • 順位は、会場前のディスプレイに出ます。
  • 制限時間は80分です
進み方

06詰まったときは


  1. チームで声に出して相談する 1台を囲んでいる意味はここにあります
  2. とりあえず試してみる　考えているだけでは進みません
  • 進行役に聞いてよいこと：操作・不具合・PCの調子・ルールの確認
  • 進行役が答えないこと：課題の答えと、解き方
詰まったときは
では、着任してください。

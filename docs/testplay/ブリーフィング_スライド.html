地獄のICT

AIを相棒に、崩れかけた病院を生き延びろ
ICT = Infection Control Team（感染制御チーム）
情報通信技術のほうではありません。
ブリーフィング

01これは、AI研修です

ゲームの形をしていますが、狙いはひとつです。

  • AIに仕事を渡せる——何が欲しいかを、言葉にして渡す
  • AIの出した物を扱える——使うか、直すか、捨てるかを自分で決める
  • AIを前提に段取りが組める——手でやるか、任せるかの判断
  • 講義はしません。聞いて覚えるのではなく、やって身につけてもらいます。
これは、AI研修です

02先に謝っておきます。これは難しいです

「地獄のICT」という名前は、誇張ではありません。

  • 難易度は下げていません。地獄のように大変です
  • 時間内に全部終わらないのが普通です。詰まる、間に合わない、失敗する
  • それも含めて、このゲームの体験です
  • できていないのは、あなたたちだけではありません。どのチームも止まっています
  • だから、手を止めて悩むより、詰まったまま試し続けるほうが前に進みます。
これは難しいです

03舞台：聖クロノス総合病院

400床・地方中核病院。電子カルテは2003年製です。

  • 皆さんは、前任のICNが急に辞めた穴を埋めるために外部から派遣された感染制御チーム
  • 今日が着任初日です。引き継ぎは、あまりありません
  • 院内では、複数の火の手が同時に上がりかけています
  • 実在の病院ではありません。登場人物も、届くメールも、全員・全部が架空です。
舞台：聖クロノス総合病院

04チームとPC

3〜4人で1チーム。ゲームに使うPCは、チームに1台だけです。

  • 個人のPC・スマホは使いません。1台を囲んでください
  • マウスはありません。トラックパッドで操作します。 （これは仕様です）
  • 役割を分けたほうが速い。おすすめは——
    • 打つ人 / 読む人 / 決める人
    • 固定せず、ステージごとに交代する（全員がAIを触ったほうが得です）
  • チーム名は、この後の入室画面でチームごとに決めてもらいます
チームとPC

05進み方

ステージ制のレースです。課題を提出して通れば、次が開きます。

  • 全チーム同時スタート。最初にゴールしたチームが優勝です
  • 順位は、会場前のディスプレイに出ます。
    • 手元のPCには、他のチームの位置は出ません
    • 気になったら、顔を上げてください
  • 全チームがゴールするまで続けます。優勝以外の賞もあります
  • 追い抜かれても、追い抜いても、やることは変わりません。

07時間と、罰

このゲームに減点はありません。罰は、時間で払います。

  • 何かを踏むと、画面に 「罰ゲーム：〜」 と出て、作業が降ってきます
  • それを終えるまで、先へは進めません
  • レースですから、時間がいちばん痛い——それが罰です
  • とはいえ、罰を恐れて止まっているほうが遅くなります。進んでください。
時間と、罰

08詰まったときは

この順番で試してください。

  1. 手元の資料を読む。必要なものは、受信トレイと共有フォルダに置いてあります
  2. AIに頼むときは、何が欲しいかを言葉にする。「やって」ではなく「何を、どういう形で」
  3. チームで声に出して相談する。1台を囲んでいる意味はここにあります
  • 進行役に聞いてよいこと：操作・不具合・PCの調子・ルールの確認
  • 進行役が答えないこと：課題の答えと、解き方 （意地悪ではなく、そういう研修です）

09入室の手順

  1. ブラウザで URL を開く
  2. 6桁のチームコードを入れる （卓の「辞令」に印字してある、自分の卓のコードです）
  3. チーム名をチームで決めて入れる（12文字まで）
  4. Enter か ［入室する］ を押す
  • 入ったら、そのまま待ってください。 全チームが揃ってから、一斉に始めます。

10いくつかお願い

  • 実在の患者さん・職員の個人情報は、絶対に入力しないでください
    • ゲームの中に出てくる名前・データは、すべて架空のものです
  • ブラウザは閉じないでください。
    • うっかり閉じても、同じチームコードで入り直せば戻れます（リロードも同じ）
    • 慌てて他のPCを触らないでください
  • 音が出ます。最初にどこかをクリックしてから鳴り始めます
  • 困ったら手を挙げてください。直せるものは、直しに行きます

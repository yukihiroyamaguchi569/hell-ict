## 方針（2026年8月9日 決定）

調査結果を踏まえ、以下を決めた。

- **山口大学9月回は研究として扱わない。** 倫理委員会は通さず、設問の作り込みと運営の確認を目的にアンケートのみ取る。ここで得た回答は**論文の解析対象に含めない**
- **ICNJ九州支部回（2026年10月31日）を研究の本番とする。** 倫理審査はこの回に向けて出し、**研究データの取得は承認後・当日以降に限る**
- **主機関は九州大学。**共同研究者は九州大学医学教育学部の菊川先生。企画者は同学部の共同研究員として参加する

この線引きの帰結として、**9月回のデータは後から論文に足せない**。倫理審査は遡れないため、9月回で「思ったより良い数字が出たので使いたい」となっても不可。9月回はあくまで設問と運営の検証に用途を限る。

同じ理由で、9月回のアンケートは「一般化可能な知見を得る」目的で設計しないこと。目的が研究に寄った時点で審査対象になる（`01` の整理を参照）。

## 調査の結論

**研究化は可能。ただし単発・少人数なら「効果検証」ではなく pilot / feasibility study として書く。**

推奨は**二段階設計**。

- **山口大学9月回 = パイロット。** 介入の純度は高いが、1セッション12〜40名では尺度検証にも群間比較にも足りない。設問の理解不能項目や天井効果を洗い出す場として使う
- **ICNJ九州支部回（2026年10月31日）= 主論文の本番。** Nと外的妥当性の両方でこちらが本命

主機関は**九州大学**（研究責任者の所属）、山口大側は共同研究機関または研究協力機関に置く。ICNJ側は開催許可と募集協力を行う研究協力機関相当。

主論文のデザインは**単群準実験研究**。アウトカムは当日終了時の retrospective pre-post による自己効力感変化、客観式知識問題、満足度、1か月後の実務転用。

### 参加者数について注意

PDFに出てくる**109名は2025年度の九州・沖縄支部地方会の参加実績**であって、2026年10月31日回の対象者数ではない。ここから解析対象数は出せない。参加者数 → 研究への同意率 → 完走率 → 1か月後の追跡残存数と、各段で減る。

`02` の「定量分析を安定させるには総計60〜120名」も、**PDF内に検定力の計算根拠はない**。教育研究の相場としての目安であり、主要評価項目・想定効果量・検定水準・検出力・脱落率を置いたサンプルサイズ計算は**研究計画書を書く段階で別途必要**。

投稿先は国内なら『医学教育』または日本シミュレーション医療教育学会雑誌、国際なら BMC Medical Education / Advances in Simulation / JMIR Medical Education。

## この企画が研究向きな理由

満足度アンケートしか残らない研修と違い、**測定可能な行動が設計に内蔵されている**。Stage 3 の罠の命中率と復旧時間、Stage 4 の PII ブロック件数、プロンプト数、NotebookLM 利用の有無、完走率。自己申告バイアスを補う客観データ源が最初からある。

## 未確定の論点

PDF自身が「依頼文では未指定」としていたもののうち、**まだ決まっていないもの**。これらが決まらないと研究計画書が書けない。

- **想定解析対象数とサンプルサイズの根拠**（上記「参加者数について注意」）
- **研究責任者を誰にするか。**九大側の受け入れ先は医学教育学部の菊川先生で確定したが、申請書に「研究責任者」として名前を出すのが菊川先生か企画者かは別問題。国の指針で研究責任者は**所属研究機関で当該研究を統括する者**と定義されており、共同研究員という身分でこれを担えるかは九大の規程による。**九大の事務窓口に確認が必要**
- **録音・録画を行うか**。インタビューを入れるなら同意文書の記載が変わる
- **AIログを申請の範囲に含めるか**（下記「2本の食い違い」）
- **1回のみか、複数回に広げるか**。10月31日回だけで60〜120名に届かない場合、学内外の追加セッションを組む必要がある

方針決定で片付いた項目：参加者属性はICNJ九州支部地方会の参加者（会員・非会員・学生を含む実務者層）。山口大学病院の内部資料は、9月回を研究にしないため研究データとしては使わない。

## 2本の食い違い

**AIログを初回論文で使うか。**

- `01` は**使わない**を推奨。ログは質問紙よりセンシティブな「学習過程データ」にあたり、NotebookLM が参加者自身のGoogleアカウント経由であることから外国にある事業者への提供の論点が乗る。初回は質問紙と客観問題に絞り、ログ解析は別研究に分けた方が倫理申請が軽い
- `02` は**採る**前提。混合研究法（前後比較＋1か月追跡＋ログ解析＋少数インタビュー）を推奨し、「ログを確実に採ること」を成否要因に挙げている

ログを**採取して保存する**ことと、**初回論文の解析に使う**ことは別。取れる設計にしておき、初回論文の解析対象から外す、という整理は両立する。ただし**倫理申請の記載範囲は先に決める必要がある**。

## 制約

- **実在患者情報は使わない。**完全な架空データ運用。これは企画側の設計判断（`CLAUDE.md` — PII は OpenAI へ送る前に Workers 側で止める）と同じ方針
- **同意はオプトアウトではなく明示的同意。**アンケートを回収した事実だけでは適切な同意にならない。最初の画面に「研究参加に同意して次へ進む」のチェックを置く
- **参加・修了証・表彰・景品と、アンケート回答の有無を完全に分離する。**案内文・司会の口頭説明・Web同意画面の三層で同じことを言う
- **本票は無記名。**氏名もメールアドレスも本票に入れない

### 前後・追跡の回答をどう結ぶか

無記名のまま個人内比較をするための仕組み。`01` の案は次のとおり。

- 参加時に**研究用IDカードをランダム配布**し、事前・事後・1か月後のすべてで**同じIDだけ**を入力してもらう。これが唯一の連結キー
- 参加者自身にコードを作らせる方式（生年月日の下2桁など）は、再現性がなく入力ミスも起きるため採らない
- 1か月後の追跡連絡が必要な場合のみ、**メールアドレスは本票とは別フォームで回収**し、別保存する。ID ↔ 連絡先の対応表は連結専用として分離管理し、アクセス権を限定する
- 保存期間は所属機関のSOPと投稿先規程を優先。実務案は**研究終了または論文公表後5年**。個票データ・本解析ファイル・同意関連文書・版管理済み質問票を分けて保存し、対応表は追跡完了後すみやかに破棄する

対応表の管理者・アクセス権・破棄時期は研究計画書に明記が必要。ここが決まらないと、匿名化と1か月後追跡を同時に満たせない。

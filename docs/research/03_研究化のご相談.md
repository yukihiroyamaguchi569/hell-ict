# 「地獄のICT」研究化のご相談

2026年8月 ／ 山口 幸洋

医療従事者向けAI研修「地獄のICT」を教育研究として論文化したく、資料をまとめました。先日ご相談しております科研費（来年春締切・秋にe-Rad申請予定）とは別の研究です。

## 1. 研修の概要

感染制御チーム（Infection Control Team）を題材にした、**ゲーム型・レース形式の生成AI研修**です。

| | |
|---|---|
| 対象 | 医療機関職員（ICT/ICN・検査技師・薬剤師・事務・看護管理者など）。AI初心者を想定 |
| 形式 | 3〜4人1組・チームに1台のノートPC・120分 |
| 舞台 | 架空の「聖クロノス総合病院」。複数のアウトブレイクが同時進行する |
| 進行 | 全チーム同時スタート。提出物が自動判定を通過すると次のステージが解錠される。最初に完走したチームが優勝 |
| 使用ツール | アプリ内蔵のGPT-4o（運営側プロキシ）と、参加者自身のNotebookLM |

**設計の中心は「速く、かつ疑え」という緊張構造**にあります。レース形式で速度を競わせながら、道中に罠を仕掛け、速さだけで突っ走るチームが沈むようにしてあります。罰は減点ではなく**時間の浪費**です。

## 2. 教材の構成

| ステージ | 課題 | 学習目標 |
|---|---|---|
| Prologue | 着任。穏やかなBGMと歓迎メール。2分後に急変する | — |
| Stage 1 火の手 | 日付形式も全角半角も混在した汚いExcelを、統一ラインリストへ整形 | データ整形をAIに任せる。手作業25分の分量が3分で終わる成功体験 |
| Stage 2 二正面 | 職員向け緊急通知・保健所への第一報・外国人家族への説明文を同時に作成 | 受け手別の書き分け。持ち帰ってそのまま使える用例集を浴びる |
| **Stage 3 嘘**（罠） | 消毒薬の希釈濃度と接触予防策の解除基準をまとめる | **ハルシネーション耐性。**GPT-4oが自信満々に嘘の基準値と存在しないガイドライン名を出す。配布マニュアルPDFをNotebookLMに読ませ、根拠ページ付きで照会するのが正解ルート |
| **Stage 4 情報漏洩**（罠） | 患者家族への返信文を作成。手元には実名・患者ID入りのカルテ抜粋（すべて架空） | **個人情報を渡さない判断。**ダミー個人情報を送信した瞬間にブロックされる |
| Stage 5 ポスター工房 | 面会制限の告知ポスターを画像生成で作成 | 画像生成のプロンプト |
| Final 記者会見 | 同じ事実を院長・家族・職員・報道の4者へ書き分ける | 受け手別の文書生成 |
| Debrief | 表彰と種明かし | 学習目標の開示、振り返り |

Stage 3 と Stage 4 が教育上の心臓部です。**Stage 1・2 で「AIは便利だ」と加速させた直後に罠を刺す**構成になっており、便利さを体験した直後だからこそ罠が刺さります。

Stage 4 のダミー個人情報は、**外部のAIサービスへ送信される前にサーバ側で遮断**します。事故を安全に体験させるための設計で、実際に外部へ出ることはありません。実在の患者情報は一切使用しません。

## 3. 研究として測定できるもの

満足度アンケートで終わる研修と異なり、**測定可能な行動が設計に組み込まれている**点が本教材の特徴です。

| 指標 | 取得方法 |
|---|---|
| Stage 3 の罠に提出まで気づけたか、復旧までの所要時間 | 提出物の自動判定 |
| Stage 4 で個人情報の送信ブロックが発火した回数 | サーバ側の検知記録 |
| NotebookLM（ソース接地型ツール）を使ったか | 提出物と操作記録 |
| 各ステージの通過時刻・完走率・総所要時間 | 進行記録 |
| 自己効力感、安全な利用判断、根拠確認の習慣、実務への転用意図 | 質問紙 |
| ハルシネーション対応・個人情報の扱い・ソース接地の使い分けに関する知識 | 客観式知識問題 |

### 取得範囲の線引き

**AIとの対話本文（プロンプトと応答そのもの）は研究データとして取得しません。**申請範囲に含めるのは、上表のイベント記録・質問紙・客観式問題に限ります。

対話本文は質問紙よりセンシティブな学習過程データにあたること、また参加者自身のアカウントで動くNotebookLMを含むと外国にある事業者への情報提供の整理が必要になることから、初回の申請を軽くする判断です。

なお研修の最終盤（Debrief）では、教育効果を高めるため、参加者本人の了解を得たうえでプロンプトを画面に映して比較する時間を設けています。これは**研修の一部であって研究データの取得ではない**ため、その旨を説明同意文書に記載する想定です。

## 4. 研究デザイン案

- **単群準実験研究。**単発・少人数の規模を踏まえ、効果検証ではなく **pilot / feasibility study** として位置づけます
- **主要評価**：当日終了時の retrospective pre-post による自己効力感の変化、客観式知識問題、1か月後の実務転用
- **符号化。**参加時に研究用IDをランダム配布し、事前・事後・1か月後を同一IDで連結します。追跡用の連絡先は本票と別に回収・別保存し、対応表は分離管理します。無記名ではなく符号化にあたるため、その用語で記載します
- **同意はデータ種別ごとに区分**します。質問紙への回答を必須、追跡連絡とインタビューを任意とし、撤回時の既収集データの扱いを同意文書に明記します
- **参加・修了証・表彰と、アンケート回答の有無を完全に分離**します。案内文・口頭説明・同意画面の三層で同じ説明を行います
- 投稿先は国内なら『医学教育』、国際なら BMC Medical Education / Advances in Simulation を想定しています

## 6. ご相談したいこと

**① 私が研究責任者を務めることは可能でしょうか。**

本研究は私が主導して進めたいと考えておりますが、共同研究員という身分で研究責任者を担えるかが規程上判断できずにおります。難しい場合は、先生に研究責任者をお願いし、私が研究分担者として実務を担う形も想定しております。

**② 9月10日提出（10月19日委員会）は現実的でしょうか。**

観察研究の審査には通常2か月程度と伺っております。10月31日の本番に承認が間に合う見込みが立つかどうか、また立たない場合の判断をいつまでに下すべきかをご教示いただきたく存じます。

**③ 申請にあたり、開催機関であるICNJ側から取得すべき文書はございますでしょうか。**

必要書類が分かり次第、ICNJ九州支部へ正式に依頼いたします。ICNJを研究協力機関とするか共同研究機関とするかも、あわせてご相談させてください。

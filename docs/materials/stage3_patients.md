## 添え状（8/23、病棟師長より）

いつもお世話になっております。3B病棟です。

平尾台医療センターさんから転院してこられた患者さん3名の件でご連絡です。転院の時点で、あちらの
皮膚科ですでに疥癬の治療（イベルメクチンの内服）を受けておられ、当院に来てからも各病棟で経過を
見ておりました。現場としては把握して対応していたのですが、ICTさんへのご報告が抜けてしまって
いたようです。

昨日（8/22）の退院調整会議で他病棟さんの件と一緒に話題に出て、「これ、ICTさんに連絡済みでしたっけ」
となり、そこで初めて気づいた次第です。転院患者さんの感染症の情報をICTさんへ回す決まった経路が
無かったことが原因のようで、一病棟だけの問題ではなさそうです。申し訳ありません。

急なお願いで恐縮ですが、3名分の状況を以下にまとめましたので、対応方針をご確認いただけますでしょうか。

## 実装メモ

- **配布経路: この教材はStage 3冒頭、3B病棟看護師長からのメール添付として届く。**上記「添え状」が
  メール本文、「転院患者3名の状況」以下が添付資料にあたる。**添え状が示す発覚の経緯
  （現場では治療が完了していたのにICTへの報告が抜けており、8/23〈テストプレイ当日〉の朝になって
  ICTが初めて事態を把握した）が、Stage 3が始まる引き金そのもの**であり、ICTは後追いで対応方針を
  決めさせられる立場に置かれる。モックへ統合する際は、この添え状をメール本文としてそのまま使うこと
  （モック統合エージェント向けの申し送り）。
- **発覚の経緯は個人の怠慢ではなく報告経路の不備として書いてある。**「現場（病棟）は疥癬のことを
  把握し、すでに治療していた」「しかしICTには連絡が来ていなかった」「転院患者の感染症情報を
  ICTへ回す決まった経路が無かった」の3点で構成し、特定の職員を名指しで責めない
  （`AGENTS.md`のトーンルール——矛先は組織と状況へ——に従う）。
- **日付の整合**: イベルメクチン内服（治療）は8/21〜8/22、発覚（退院調整会議）は8/22、
  ICTへの報告メールは8/23（テストプレイ当日）。この順序――治療が先に完了しており、翌日以降の
  会議で報告漏れが発覚し、その翌朝ICTへ連絡が来る――を崩さないこと。
- **この教材が正解導出の根拠そのものである。**`stage3_manual.md`（正典）が「通常疥癬は、治療完了後
  24時間経過をもって標準予防策のみに戻す」という**基準**を示し、本教材が「この3名は治療完了・
  最終治療から1日以上（24時間以上）経過」という**事実**を示す。両者を突き合わせて初めて「標準予防策へ
  戻してよい」という結論に到達する——`stage3_manual.md`だけでは治療状況が分からず、本教材だけでは
  判断基準（何時間経てば解除できるか）が分からない設計にしてある。
- **病型（通常型か角化型か）は本教材にはあえて書かない。**転院元が角化型疥癬の発生施設であることは
  示すが、この3名自身の病型は断定しない。判断の材料は「治療完了」と「最終治療からの日数」だけであり、
  参加者はマニュアルの解除基準（治療完了後24時間）をこの2点に適用して結論を出す。病型そのものは、
  罠を踏んだ場合に皮膚科医の指摘で初めて明かされる構図にしてある（下記「皮膚科医の叱責台詞」1・3）。
- **3名分そろって同じ結論（治療完了・1日以上経過・改善傾向）が読み取れる**ことが肝。1名だけ経過日数が
  足りない、といった例外は置かない（Stage 3の主眼は過剰対応の罠であり、経過日数の読み間違い探しを
  別途混ぜると論点がぼやける）。
- **日付はテストプレイ実施日（8/23）を基準にしている。**イベルメクチン内服日を8/21または8/22とし、
  8/23時点でいずれも「最終治療から1日以上（24時間以上）」を満たす（8/21起点は2日、8/22起点は1日）。
  テストプレイ日が変わる場合は、この起点日・発覚日・報告日をまとめてずらすこと。
- **患者ID `T-101` / `T-102` / `T-103` は、Stage 2 ラインリスト（`stage2_linelist.tsv` の `001`〜`020`、
  `stage2_linelist_addendum.tsv` の `021`〜`030`）およびその中の伏線3名（`005` / `6` / `008`、原因不明
  発熱の疑い）と重複しない番号にしてある。** 番号体系自体も別系統（`T-` 接頭辞）にして、この3名が
  ラインリストの患者とは無関係な転院患者であることを一目で区別できるようにした。
- **「謎の発熱」（未知ウイルス）の縦軸とは無関係。** 3名とも発熱等の全身症状はなく、本文中に「発熱」
  の語を一度も持ち込んでいない。読者が誤って未知ウイルスの伏線と結び付けないための配慮。
- **病棟は3名をあえてバラバラ（3B／5B／6A）にしてある。**既存教材で使われている病棟名の流儀
  （`stage2_linelist.tsv`の5A病棟、`docs/scenario/`の3B病棟・5B病棟等）から選び、転院患者らしく
  複数病棟へ分散して受け入れられた体裁にした。原因不明発熱の患者005の病棟（5A）とは重ならないように
  避けてある（`6`・`008`はラインリスト上で病棟欄が空欄のため、重複判定の対象にしていない）。
  発行者を添え状の差出人として自然な「T-101の受け入れ先である3B病棟」の看護師長にしてある。
- 転院元「平尾台医療センター」は架空の施設名。実在の医療機関と紛らわしくないよう配慮した。
- **皮膚科医の叱責台詞（罠発動時）の案**（気難しいが、判断と状況へ向ける。人格攻撃はしない）。
  この場面が病型（通常型）を参加者に初めて明かす役割を持つ:
  1. 「誰です、全員に予防衣なんて指示を出したのは。通常疥癬ですよ。治療も終わってる。カルテは
     読みましたか」
  2. 「不要な隔離は患者を弱らせます。全部外してください」
  3. 「角化型と通常型を一緒くたにするから、こうなる。この3人は通常型です。次からは病型と治療の
     進み具合を先に見てください」

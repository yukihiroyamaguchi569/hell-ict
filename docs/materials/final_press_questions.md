## 質問一覧

```
【記者クラブ事前質問】

1. 現在、院内で「聖クロノス熱（仮）」と呼ばれている感染症の患者数は何名ですか。

2. 感染経路は特定できていますか。飛沫感染ですか、接触感染ですか。

3. この病気の潜伏期間はどのくらいですか。

4. 重症化率、致死率について教えてください。

5. 病院として、現在どのような感染対策を行っていますか。

6. 面会制限や消毒など、患者・ご家族に対する具体的な対応を教えてください。

7. いつ終息する見込みですか。

8. 患者の氏名や病棟など、個別の患者情報について教えてください。
```

> 📌 **この文面は「嘘」ではない。** Stage 3 の汚染教材（誤った基準値を仕込んだ罠）とは性質が異なり、
> 質問そのものに誤りは無い。**答えられる質問と、原理的にまだ答えられない質問が混在しているだけ**——
> 現場が意地悪しているのではなく、[`../scenario/00_未知ウイルスの通奏低音.md`](../scenario/00_未知ウイルスの通奏低音.md)
> §1 の保留設定（感染経路・病原体の正体・潜伏期・致死率は「最後まで割らない」）がそのまま反映されている。

### 答えられる質問／答えられない質問の対応

| 質問 | 性質 | 参照先 |
|---|---|---|
| 5. 現在の感染対策 | **答えられる** | 正典 [`stage3_manual.md`](stage3_manual.md) 5-2・5-3（消毒0.1%・個室/コホーティング・マスク/N95） |
| 6. 患者・ご家族への具体的対応 | **答えられる** | 正典 5-3・5-4（隔離・接触予防策）＋ Stage 5 の面会制限 |
| 1. 患者数 | **答えられる範囲で** | 院内状況インジケータ（14）が示す事実そのもの。数字は言えるが、確定病名は言えない |
| 2. 感染経路 | **答えられない** | 縦軸 §1「保留」。最後まで割らない |
| 3. 潜伏期間 | **答えられない** | 縦軸 §1「保留」 |
| 4. 重症化率・致死率 | **答えられない** | 縦軸 §1「保留」 |
| 7. 終息見込み | **答えられない** | 病原体未確定＝解除基準が決まらない（正典 5-4「病原体が確定するまで軽い側に倒してはならない」） |
| 8. 個別の患者情報 | **答えてはいけない** | Stage 4 の送信前ゲート・Final の④誤り判定と同じ理由（個人情報） |

## 実装メモ

- このファイルは**判定に使う正規表現の情報源ではない**。Final の判定は4欄の提出テキストに対して行われ、
  この質問文をそのまま判定パターンへ流用する必要は無い（`docs/ui/mock/README.md` Final 節・
  [`../ui/07_Final.md`](../ui/07_Final.md) 実装メモ）。
- 添付ビューアで開く用のテキストは、上記「質問一覧」のブロックをそのまま使う。要約せずに全文表示する。
- `[コピー]` ボタンは UI 側に**置く**（[`../ui/07_Final.md`](../ui/07_Final.md) 参照）。質問リストを
  AI に貼って下書きさせる動線は正当であり、Stage 4 のような漏洩の罠がここには無いため。
- **8番の質問に対する「答えてはいけない」の判定は、この教材ではなく Stage 4 の
  [`stage4_chart.md`](stage4_chart.md)（`S4_PATIENT`）を単一の情報源として行う。** ここに新しく
  患者の固有情報を書き足さない——教材と判定を二重管理しないための構成。

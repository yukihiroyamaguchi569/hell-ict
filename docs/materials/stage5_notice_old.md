## 掲示物本文

```
【面会制限のお知らせ】

平素より当院の感染対策にご理解・ご協力を賜り、誠にありがとうございます。
下記の通り、面会制限を実施しておりますので、何卒ご了承のうえご来院くださいますよう
お願い申し上げます。

1. 面会は原則としてご遠慮いただいております。やむを得ない事情がある場合に限り、
   病棟スタッフステーションまでお申し出ください。
2. やむを得ず面会される場合は、必ずマスクを着用のうえ、15分以内でお願いいたします。
3. 面会可能な時間帯は、平日・休日を問わず午後2時から午後4時までとさせていただきます。
   上記以外の時間帯での面会はお受けできませんので、あらかじめご了承ください。
4. 発熱・咳症状等がある方は、ご家族であっても面会をご遠慮いただいております。
5. 面会される方は、入館時に受付にて検温にご協力ください。
6. その他、病棟の状況により追加の制限をお願いする場合がございます。

ご不便をおかけいたしますが、患者様の安全確保のため、何卒ご理解のほどお願い申し上げます。

聖クロノス総合病院 総務課
```

> 📌 **この文面は「嘘」ではない。** Stage 3 の汚染教材（誤った基準値を仕込んだ罠）とは性質が異なり、
> 内容自体はStage 5の必須要素（マスク着用・面会時間）を満たしている。**不評だった理由は中身ではなく
> 見た目**——文字だけがびっしり並び、多言語対応もピクトグラムも無いという体裁の問題。
> 苅部さんの「誰も読まなかったのは字が多かったからです」（[`../scenario/06_Stage5_ポスター工房.md`](../scenario/06_Stage5_ポスター工房.md)
> §苅部さん）が指しているのはこの一点だけであり、内容の正しさは否定しない。

## 実装メモ

- このファイルは**判定に使う正規表現の情報源ではない**。Stage 5 の判定はプロンプト文字列に対して
  行われ、この教材の文言をそのまま判定パターンへ流用する必要は無い
  （`docs/ui/mock/README.md` Stage 5 節・[`../ui/06_Stage5.md`](../ui/06_Stage5.md) 実装メモ）。
- 添付ビューアで開く用のテキストは、上記「掲示物本文」のブロックをそのまま使う。
  改行・箇条書きの多さそのものが「読みにくさ」の実物なので、要約せずに全文表示する。
- `[コピー]` ボタンは UI 側に置かない（[`../ui/06_Stage5.md`](../ui/06_Stage5.md) §1「やらないこと」）。
  読むだけで足りる教材であり、AIへ渡す動線を作る必要が無い。

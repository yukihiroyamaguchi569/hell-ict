## 発熱対応早見表（原因不明時）

| 項目 | 対応 |
|---|---|
| PPE | 標準予防策に準じて対応する |
| 接触予防策の解除 | **解熱をもって解除する** |
| 環境消毒 | 通常通りの清掃・消毒とする。あわせて**壁・床を含め、病室全体を広く消毒する** |

> 出典: **全国病院感染対策協議会（NHICC）「発熱性疾患対応ガイドライン 2013年版」**

## 実装メモ

- 3つの誤りが `stage3_manual.md` §5-2〜5-4 と1対1で対置される。**いずれも「〜で十分」のような断定で自ら怪しさを出さない**——正典が要求する上乗せが**書かれていないこと**（不作為）で誤る形にしてある。
  | 欄 | 誤り方 | 正典（5-2〜5-4） |
  |---|---|---|
  | PPE | 標準予防策**止まり**。マスク常時着用・アイシールド・N95の条件付き使用・有症状スタッフの就業停止がどれも無い | 標準予防策に**加えて**それらを行う |
  | 解除 | 解熱という**症状ベース**の基準 | 時間や解熱を根拠にしない。病原体確定 or 新規発生14日間ゼロ |
  | 環境消毒 | 「通常通り」＝日常清掃止まりで次亜塩素酸0.1%の指定が無い。一方で壁・床の全面消毒という**古い過剰対応**が乗る | 次亜塩素酸ナトリウム 0.1%（1000 ppm）を高頻度接触面に |
- **環境消毒を表の最下段に置く。** 一番手薄な項目を最後に回し、上2つを読んだ時点で判断を終えたチームが取りこぼすようにする。「やることは多いが的外れ」（壁・床は磨くが濃度指定は無い）という配置自体が、古い現場メモらしさになる。
- **隔離・コホーティングの行は置かない。** 正典（`stage3_manual.md` 5-3）にはあるが、この早見表には**行そのものが無い**。
  提出フォームの欄名は「PPE・隔離」のままなので、早見表だけで済ませたチームは隔離について書けない——**4つ目の誤り＝不作為**として機能する。
  「書いてあることが違う」ではなく「**書かれていない**」に気づけるかを問う設計なので、ここに隔離の行を足さないこと。
- **「全国病院感染対策協議会（NHICC）」は実在しない架空の団体名。** 実在の学会・団体と紛れないよう選定した（CLAUDE.md トーンルール「実在の病院・人物名は出さない」の精神を団体名にも適用）。
- **判定（モック `S3_TRAP`）との対応**。どれも「罠語があり、かつ正解語が無い」形にしてあり、正典を読んだ上で
  「アルコールでは不十分」「解熱を根拠にしない」と**正しく否定して書いた提出は誤爆しない**（否定形は罠ではなく理解の証拠）。
  | 欄 | 罠の検出条件 |
  |---|---|
  | PPE | `標準予防策` があり、上乗せ語（`個室`/`コホー`/`N95`/`有症状`/`常時`/`アイシールド`）がひとつも無い |
  | 解除 | `解熱`（または `解熱後\d+時間`）があり、`確定`/`14日`/`新規発生` が無い |
  | 環境消毒 | `通常通り` または（`壁` かつ `床`）があり、`次亜塩素酸` が無い |
  | 出典（横断） | `NHICC`／`全国病院感染対策協議会`／`発熱性疾患対応ガイドライン` |
- **隔離欄の不作為は罠として発火させない。** 早見表に隔離の行が無いことによる書き漏らしは「嘘を書いた」ではなく
  「まだ書けていない」なので、`S3_REQUIRED.ppe` の `個室|コホー` を満たさない＝**差し戻し（無罰）**として扱う。
- AIチャットへの参加者の貼り付けを想定した文面なので、**AIがそのまま復唱しやすい定型フォーマット**（表＋出典明記）にしてある。Stage 3 のシステムプロンプト注入（企画書 §7 二段構え目）も、この3つの誤答と同じ内容を返す。

## 疥癬対応早見表

| 項目 | 対応 |
|---|---|
| 隔離 | **個室隔離とする** |
| PPE | **入室時は予防衣・手袋を常時着用する** |
| リネン・寝具 | **殺虫剤処理または50℃以上の熱処理を行う** |
| 環境 | **退室後の病室に殺虫剤を散布する** |
| 予防策の解除 | 慎重に判断し、**治療後も当面（2週間程度）接触予防策を継続する** |

> 出典: **全国療養施設感染管理連絡会「疥癬対応の手引き 2009年版」**

## 実装メモ

- 罠語の案: 「個室（隔離）」「予防衣」「殺虫剤」「熱処理」「継続（当面・2週間）」。
  いずれも角化型（痂皮型）疥癬向けの対応であり、通常疥癬には過剰。
- 誤りの正体は「病型を確認しないまま、最も厳重な対策（角化型向け）を疥癬全般に一律適用している」
  ことであり、個々の対応（個室隔離・予防衣・殺虫剤処理・熱処理）は単体では医学的に誤りではない。
  **角化型に対してなら概ね正しい。**これは従来のノロウイルス版（対応不足を突く罠）とは逆で、
  **過剰対応を突く罠**である（`docs/materials/README.md` を参照。この版から罠の向きが反転した）。
- 罠の検出は `stage3_manual.md` 実装メモと同じく「罠語があり、かつ正解語が無い」形にする。
  「角化型ではないので個室隔離・予防衣は不要」「通常疥癬なので標準予防策のみで対応する」のように、
  罠語を引用したうえで正しく否定した提出を誤爆させない。
- **Workerのシステムプロンプト注入（`apps/worker/src/stage-prompts.ts` の `STAGE3_SYSTEM_PROMPT`）と
  内容を一致させてある。**AIチャットの罠応答も本早見表と同じ4点（個室隔離／予防衣・手袋常時着用／
  殺虫剤処理または50℃以上の熱処理／解除は慎重に・当面継続）を断定的に返し、通常疥癬との区別や
  24時間解除基準には一切触れない。教材とAI応答のどちらから罠に触れても、参加者が受け取る誤情報が
  一致するようにする。表記を変える場合はこの2箇所を同時に直すこと（構造は変えても、罠として
  機能する4点の対応内容は揃えたままにする）。
- 「全国療養施設感染管理連絡会」「疥癬対応の手引き 2009年版」は架空の団体・文書名。実在の団体・
  ガイドラインと混同させない。2009年という古い年式は、正典（第7版・当院基準の24時間ルール）が
  更新済みであるのに対し、この早見表が更新されていないことを示す手がかりとして機能する。

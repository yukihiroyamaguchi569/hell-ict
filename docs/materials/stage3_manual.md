## 第5章 病原体不明の集団発生への対応（p.42–47）

### 5-1 基本方針（p.42）

原因微生物が未確定の集団発生（アウトブレイク）に対しては、環境消毒・接触予防策の解除基準を**病原体が確定するまで軽い側に倒してはならない。** 一方でPPEはリスクに応じた段階的な運用とし、不必要な最大防護は求めない（詳細は5-3）。確定後は該当する対応のみへ見直す（デ・エスカレーション）。

### 5-2 環境消毒（p.43）

| 対象 | 使用薬剤 | 濃度 |
|---|---|---|
| 病室・共用設備の環境消毒 | **次亜塩素酸ナトリウム** | **0.1%（1000 ppm）** |
| 血液・体液の付着がある場合 | 次亜塩素酸ナトリウム | 0.5%（5000 ppm） |

> 病原体が未確定の段階では、アルコール系消毒薬のみでの対応は**不十分**とする。
> 広域スペクトルを持つ次亜塩素酸ナトリウムを標準とし、病原体確定後に薬剤を見直す。

### 5-3 個人防護具（PPE）と隔離（p.44）

| 項目 | 暫定対応 |
|---|---|
| 隔離・コホーティング | 個室管理を原則とする。個室が確保できない場合は、**同一症候の患者を同室にまとめるコホーティング**を行う |
| マスク | 病棟内では全スタッフがサージカルマスクを常時着用する |
| 発熱患者の直接ケア | サージカルマスク＋アイシールド／ゴーグルを暫定的に使用する |
| 手指衛生 | 患者接触前後・PPE着脱時を特に徹底する |
| 手袋・ガウン | 標準予防策に従う。分泌物・体液曝露が予想される場合に着用し、下痢・嘔吐などがあれば接触予防策へ切り替える |
| N95 | 全員一律には不要。エアロゾルが発生する処置では使用する。麻疹・水痘・結核など空気感染が疑われた時点でN95＋空気予防策を適用する |
| スタッフ移動 | 可能な限り、発生病棟と他病棟との応援・兼務を減らす |
| 有症状スタッフ | 発熱・咽頭痛・咳・下痢などの症状が出たスタッフは勤務させず、速やかに評価・検査する |
| 休憩室 | マスクを外すスタッフ同士の長時間接触を減らし、換気・人数制限を行う |

### 5-4 接触予防策の解除基準（p.45）

> **解除基準は、時間や解熱を根拠にしない。**

以下の**いずれか**を満たすまで、接触予防策を解除しない。

1. **病原体が確定し、確定した病原体に応じた基準へ切り替わったとき**
2. **新規発生が所定期間（当院基準では14日間）ゼロとなったとき**

> 📌 「解熱後◯時間で解除可」「症状消失後◯日で解除」といった**時間ベースの基準は、病原体が未確定の段階では使用しない。** 病原体ごとに排菌期間・感染性の持続期間が異なるため、確定前に時間で区切ることは科学的根拠を欠く。

## 実装メモ

- **判定に使う文字列はこの節から取る**: 「次亜塩素酸ナトリウム」「0.1%」「1000 ppm」「病原体が確定」「新規発生」「14日間」。
  PPE欄（5-3）は `個室|コホー` と `N95|マスク` の2つを必須にしてある（モック `S3_REQUIRED.ppe`）——
  **隔離を必須にするのが要点**で、汚染教材には隔離の行が無いため、早見表だけで済ませたチームは構造的にこの欄を満たせない。
  環境消毒は薬剤名に加えて濃度（`0.1|1000`）も必須。罠側は「濃度指定が無い」ことが誤りの本体なので、濃度が正典を読んだ証拠になる。
- **5-3 の「隔離・コホーティング」は汚染教材（`stage3_contaminated.md`）に対応する行が無い。** 提出フォームの欄名は
  「PPE・隔離」のままなので、早見表だけを頼りにしたチームは隔離について書くことができない——**書かれていないことに気づけるか**を問う不作為型の罠。
  この非対称は意図的なので、早見表側に隔離の行を足さないこと。
- PDF 生成時も章番号・ページ番号（p.42〜47）を維持する（マニュアルらしい体裁のため）。
- **`stage3_contaminated.md`（汚染教材）と絶対に取り違えない。** ファイル名にも内容にも「正典」「汚染」の区別を明示してある。

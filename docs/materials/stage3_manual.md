## 第5章 疥癬（かいせん）への対応（p.42–47）

### 5-1 基本方針（p.42）

疥癬はヒゼンダニの寄生によって起こる皮膚感染症で、**病型によって感染力も必要な対策もまったく異なる。**
「疥癬」とだけ聞いて対応を決めてはならない。**病型（通常疥癬か角化型〈痂皮型〉疥癬か）と治療の進捗を
必ず確認したうえで、対応を選ぶ。**病型を確認しないまま一律に厳重な対策を続けることは、現場の負担を
無意味に増やし、患者の療養環境を損なう。過剰な対応もまた誤りである。

### 5-2 病型ごとの違い（p.43）

| 項目 | 通常疥癬 | 角化型（痂皮型）疥癬 |
|---|---|---|
| 感染力 | 弱い。長時間の直接皮膚接触が主な感染経路 | 極めて強い。虫体数が桁違いに多く、寝具・衣類等の間接接触でも感染しうる |
| 隔離 | **不要**。標準予防策で対応する | 個室隔離とする |
| PPE | 標準予防策（通常のケアに準じる） | 入室時に予防衣・手袋を着用する |
| リネン・寝具 | **通常の洗濯でよい** | 50℃・10分の熱処理等、虫体を死滅させる処理を行う |
| 環境（殺虫剤） | **不要** | 必要に応じて環境処理を検討する |
| 治療 | 疥癬治療薬（イベルメクチン内服等） | 同左。ただし治療完了まで対策を継続する |

> 表の「通常疥癬」列がこの章の主眼である。角化型は感染力が桁違いに強い例外であり、
> 通常疥癬に角化型の対策をそのまま当てはめると、必要のない隔離・防護具・殺虫剤処理を
> 積み重ねることになる。

### 5-3 通常疥癬への対応（p.44）

通常疥癬の患者に対しては、**個室隔離は不要であり、標準予防策で対応する。**接触予防策や個室管理を
上乗せする必要はない。治療は疥癬治療薬（イベルメクチン内服等）による。リネン・寝具は**通常の洗濯**で
よく、殺虫剤の散布は**不要**である。

### 5-4 角化型（痂皮型）疥癬への対応（p.45）

角化型疥癬の患者に対しては、個室隔離としたうえで接触予防策を実施する。入室時は予防衣・手袋を
常時着用する。リネン・寝具は50℃・10分の熱処理等を行う。これらの対策は治療完了まで継続する。

### 5-5 予防策の解除基準（当院基準）（p.46）

> 通常疥癬か角化型かで解除の考え方が異なる。混同しない。

- **通常疥癬**: 治療（イベルメクチン内服等）が完了し、**最終投与から24時間が経過した時点**で、
  追加していた予防策があればすべて解除し、**標準予防策のみに戻す。**皮疹の改善傾向も確認するが、
  解除の可否を左右するのは治療完了と経過時間である。
- **角化型（痂皮型）疥癬**: 個室隔離・接触予防策は**治療完了まで継続**する。自己判断での早期解除は
  行わない。

### 5-6 判断の原則（p.47）

1. 「疥癬」という診断名だけで対策を決めない。病型（通常疥癬か角化型か）を確認する。
2. 転院・転棟してきた患者については、転院元での病型と治療経過（投与薬剤・完了日）を確認する。
3. 通常疥癬の接触者が通常疥癬を発症するのは疫学的に想定内であり、それ自体は角化型の存在を
   意味しない。接触者の病型も個別に確認する。
4. 治療完了後24時間が経過した通常疥癬患者に、角化型向けの対策（個室隔離・予防衣常時着用・
   殺虫剤処理・長期の接触予防策継続）を漫然と続けることは、過剰対応であり誤りである。

## 実装メモ

- 判定は3欄（環境・リネン欄／PPE・隔離欄／解除欄）で行い、**すべての欄が正解語を満たして初めて
  「足りている」**とする（Stage 3従来の枠組みを踏襲）。
  - **①環境・リネン欄**: 必須語の案は「通常」（通常の洗濯）と「殺虫剤」＋「不要」（殺虫剤は不要、の趣旨）。
  - **②PPE・隔離欄**: 必須語の案は「標準予防策」と「個室」＋「不要」（個室隔離は不要、の趣旨）。
  - **③解除欄**: 必須語の案は「治療完了」と「24時間」。「標準予防策」を併記していればなお良いが、
    ②で既に評価しているため必須条件の重複は避ける。
- **罠判定は「罠語があり、かつ正解語が無い」形を維持する。**
  具体的には、罠語（「個室」「予防衣」「殺虫剤」「熱処理」「継続」等）が本文に出現していても、
  同じ欄に対応する正解語（「不要」「標準予防策」「治療完了」「24時間」等）が併記されていれば
  罠発火にしない。**「角化型ではないので個室隔離・接触予防策は不要」「通常疥癬なので標準予防策の
  みで対応する」のような、罠語を含む正しい否定文を誤爆させないため**である（`stage3_contaminated.md`
  実装メモと対応させる）。
- 汚染教材（`stage3_contaminated.md`）は角化型向けの過剰対応をそのまま「疥癬対応早見表」として
  提示する。角化型という語は汚染教材に一切出てこない——出せば罠だと気づかれる。
- 正解の根拠（治療完了・最終治療からの日数）は本マニュアルではなく
  `stage3_patients.md`（転院患者3名のサマリ）にある。`stage3_patients.md`は病型を明示しない
  ——参加者は本マニュアルで「通常疥癬なら、治療完了後24時間経過をもって標準予防策のみに戻す」
  という基準を知り、`stage3_patients.md`で「この3名は治療完了済み・最終治療から1日以上（24時間以上）
  経過」という事実を確認して初めて、両者を突き合わせて正解に到達する。病型そのものは罠発動時に
  皮膚科医の指摘で初めて明かされる（`stage3_patients.md`実装メモ参照）。
- Worker側のシステムプロンプト注入（`apps/worker/src/stage-prompts.ts` の `STAGE3_SYSTEM_PROMPT`）は、
  角化型向けの過剰対応（個室隔離・予防衣常時着用・殺虫剤処理／熱処理・接触予防策の当面継続）を
  断定的に答え、通常疥癬との区別や24時間解除基準には一切触れない設計になっている。本マニュアルの
  記述と対応するAI回答が矛盾しないよう、語彙（「個室隔離」「予防衣」「殺虫剤処理」「50℃」
  「標準予防策」「24時間」等）を揃えてある。
